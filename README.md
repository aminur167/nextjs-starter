# Next.js Starter Project

Next.js application template with TypeScript, Tailwind CSS, and App Router configuration for modern full-stack development.

## Features

- Next.js App Router (app directory)
- TypeScript support
- Tailwind CSS styling
- ESLint configuration
- Optimized for development and production

## Getting Started

```bash
cd my-app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
